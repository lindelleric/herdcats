Optional Herdcats Bridge (`herdcats-bridge`) for Herdcats native Claude and Codex Timelines.

Changes in this release:
- Support for Codex conversation history and live timelines alongside Claude.
- Codex rollouts are followed from $CODEX_HOME/sessions (or ~/.codex/sessions) with strict session identity, directory confinement, and duplicate detection.
- Codex timelines require an exact session reference from Herdr, which requires Codex's shared daemon to be off or running sessions with codex --no-daemon.
- New Herdcats Bridge subcommand `herdcats-bridge codex-config disable-daemon` powers the in-app "Turn off" button, safely updating features.daemon_auto_start in config.toml while preserving user formatting and creating a backup.
- Images have individual Timeline entries and on-demand original bytes instead of being omitted from streamed records.
- Unfamiliar records and content blocks get fallback bubbles with complete original source access.
- Text and tool entries retain links to their original records, including output shortened in previews.
- Bounded content chunks revalidate the current native session, source generation and published reference before retrieval; no host file paths are accepted.
- Rich content is negotiated explicitly; older clients keep the existing message/tool protocol behavior.
- Large inline images stay out of live event frames. Existing transcript size, identity and retention bounds remain enforced.

Install on the direct SSH computer that owns Herdr and the agent transcripts:

curl -fsSL https://github.com/zhiyao/herdcats/releases/download/herdcats-bridge-v__BRIDGE_VERSION__/install.sh | sh -s -- --version __BRIDGE_VERSION__

Requires macOS 13+ or Linux with glibc 2.35+ (Ubuntu 22.04+), curl and SHA-256 tooling. Apple Silicon, Intel Mac, Linux arm64 and x86_64 binaries are included. Herdr protocol 22 and an exact Claude or Codex session reference are required. No root access, Rust, Python, hooks or persistent service required. Existing installation upgrades require --replace.

Checksums detect damaged downloads; they are provided through the same HTTPS release channel. These binaries are not Developer ID signed/notarized. Native question/approval responses and saved-machine routing remain unavailable; use Terminal for those interactions.

After installation, return to Herdcats and tap Check again.
