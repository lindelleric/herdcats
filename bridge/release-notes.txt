Herdcats Bridge (`herdcats-bridge`) is the optional companion on your computer that powers native Claude and Codex Timelines in Herdcats.

Changes in this release:
- Change the model and reasoning effort of a Claude or Codex session from your phone. The bridge reads the current model from the session, then types `/model` or `/effort` only when the agent is idle and its input box is empty, and checks every screen before the next key. Claude's "Switch model?" question is answered only when it names exactly what you picked.
- Codex changes apply to that session only and never write config.toml. Claude saves the new model and effort as your default for new sessions, as `/model` and `/effort` do at your desk.
- Claude timelines no longer show local command records such as `/effort` and its output.

Install on the computer Herdcats connects to with SSH, the one that runs Herdr and your agents:

curl -fsSL https://github.com/zhiyao/herdcats/releases/download/herdcats-bridge-v__BRIDGE_VERSION__/install.sh | sh -s -- --version __BRIDGE_VERSION__

Requires macOS 13+ or Linux with glibc 2.35+ (Ubuntu 22.04+), curl and SHA-256 tooling. Apple Silicon, Intel Mac, Linux arm64 and x86_64 binaries are included. Herdr protocol 22 and an exact Claude or Codex session reference are required. No root access, Rust, Python or persistent service required. Phone answers for Claude, and for Codex approvals, use an optional recording hook that Herdcats installs only after you confirm. Existing installation upgrades require --replace.

Checksums detect damaged downloads; they are provided through the same HTTPS release channel. These binaries are not Developer ID signed/notarized. Saved-machine routing remains unavailable.

After installing, return to Herdcats and tap Check again.
